# Contributing to Nexora AI Agent

Thanks for helping improve Nexora.

## Before opening a change

1. Keep changes focused and describe the user-facing effect.
2. Build with JDK 17, Gradle 8.9, and Android SDK Platform 35.
3. Check the GitHub Actions workflow result.
4. Do not commit API keys, signing files, local.properties, or other secrets.
5. Keep the app's API integration restricted to endpoints you own or are authorized to use.

## Bug reports

Include device/Android version where relevant, reproduction steps, expected behavior, actual behavior, and build logs with all secrets removed.

## Pull requests

Explain the problem being solved, summarize the changes, and mention how they were tested. If the change affects UI, include screenshots when possible.
